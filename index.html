Eyezheimer

ซอฟต์แวร์ AI วิเคราะห์ภาพจอประสาทตา OCTA เพื่อคัดกรองโรคอัลไซเมอร์ระยะเริ่มต้น · “คัดกรองวันนี้ เพื่ออนาคตที่ดีกว่า”

สรุปในประโยคเดียว: เว็บแอปสำหรับแพทย์ อัปโหลดภาพ OCTA ขนาด 3×3 มม. แล้ว U-Net จะแยกเส้นเลือดฝอยทีละพิกเซล ระบบหาพื้นที่ FAZ (บริเวณกลางจอตาที่ไม่มีเส้นเลือด) เป็น mm² แล้วเทียบกับค่าจากงานวิจัยออกมาเป็นดัชนี Alzheimer (0–1) และ % ความเสี่ยงตามอายุ จากนั้นแพทย์ต้องตรวจและอนุมัติก่อนออกรายงาน PDF / DICOM
ประโยคที่ต้องพูดให้ชัดทุกครั้ง: ระบบนี้ใช้ คัดกรอง ไม่ได้ใช้ วินิจฉัย · AI ที่เทรนจริงทำหน้าที่ แยกเส้นเลือด ส่วนดัชนี Alzheimer คำนวณจากค่าสถิติในงานวิจัยที่ตีพิมพ์แล้ว ยังไม่ใช่ตัวจำแนกโรค (classifier) ที่ผ่านการทดสอบกับผู้ป่วยจริง

คณะผู้จัดทำ: นายฐิติโชติ ทับแสง · นายปภังกร ตราชู · นายไชยพร เกรียงไกรวิทย์ — ครูที่ปรึกษา: นางวาสนา หงษ์ษา · นางณัชชา บุญประไพ

สรุปทีละบอร์ด (อธิบายละเอียด)

บอร์ด 1 — ที่มาและความสำคัญ / วัตถุประสงค์ / ขอบเขต / ประโยชน์

ปัญหา: ไทยเข้าสู่สังคมผู้สูงอายุ อัลไซเมอร์เป็นสาเหตุหลักของภาวะสมองเสื่อม ตัวอย่างบนบอร์ดคือ “ป้าจีน 67 ปี” ลืมบ่อย ถามซ้ำ หลงทาง แต่คิดว่าแค่เหนื่อย กว่าจะพบแพทย์เซลล์ประสาทก็ถูกทำลายไปมากแล้ว

วิธีตรวจเดิมมี 3 ปัญหา: PET scan ราคาสูง · เจาะน้ำไขสันหลังทำให้ผู้ป่วยกลัว · แพทย์อ่านภาพด้วยตาใช้เวลานานและอ่านไม่ตรงกัน 15–20%

วัตถุประสงค์ 3 ข้อ: (1) พัฒนาซอฟต์แวร์ AI วิเคราะห์ภาพ OCTA วัดเส้นเลือดฝอยและ FAZ (2) ทำให้การคัดกรองเข้าถึงง่าย ไม่เจ็บ เร็ว ถูก (3) ช่วยแพทย์ตัดสินใจอย่างมั่นใจ แพทย์ตรวจก่อนออกผล และปกป้องข้อมูลผู้ป่วย

ขอบเขต: ผู้ใช้ = แพทย์/บุคลากรการแพทย์ · ข้อมูลเข้า = ภาพ OCTA 3×3 มม. (PNG, JPEG, TIFF) · ผลลัพธ์ = ดัชนี Alzheimer และ % ความเสี่ยง · เว็บแอป 11 เมนู · ความปลอดภัย = ล็อกอิน, บันทึก log, เซ็นผลด้วย HMAC · ข้อจำกัด = ใช้คัดกรอง ไม่ใช่วินิจฉัย

บอร์ด 2 — ชื่อโครงงาน / ทฤษฎี / จุดเด่น / ขั้นตอนดำเนินงาน

ทฤษฎี 3 เรื่อง:

  • อัลไซเมอร์: โรคสมองเสื่อมที่พบบ่อยที่สุด เซลล์ประสาทถูกทำลายหลายปีก่อนแสดงอาการ ตรวจเร็วช่วยชะลอได้
  • จอประสาทตา = หน้าต่างสู่สมอง: จอประสาทตาเจริญมาจากเนื้อเยื่อเดียวกับสมอง (ส่วนหนึ่งของระบบประสาทส่วนกลาง) ผู้ป่วยอัลไซเมอร์มี เส้นเลือดฝอยลดลง และ FAZ ใหญ่ขึ้น
  • OCTA + AI: OCTA (Optical Coherence Tomography Angiography) ถ่ายภาพเส้นเลือดฝอยใน 1–2 นาที ไม่ต้องฉีดสี ใช้ U-Net แยกเส้นเลือดทีละพิกเซลแล้ววัดพื้นที่ FAZ

ข้อมูลส่วนนี้มาจากโค้ดจริงในโปรเจกต์: backend/app/octa_pipeline.py, model_card.json, features/clinical-console/alzheimer-risk.ts, server/analysis-receipt.ts

1. รับไฟล์และตรวจความปลอดภัยของภาพ

  • ไฟล์ว่าง → ปฏิเสธ · ใหญ่กว่า 8 MB → ปฏิเสธ · เล็กกว่า 64×64 พิกเซล → ปฏิเสธ · เกิน 16 ล้านพิกเซล → ปฏิเสธ (กัน decompression bomb)
  • ต้อง decode ได้จริงเป็น JPEG/PNG/WebP/TIFF และชนิดที่ประกาศ (MIME) ต้องตรงกับที่ decode ได้ — กันการเปลี่ยนนามสกุลไฟล์หลอก
  • ไม่รับภาพหลายเฟรม (เช่น TIFF หลายหน้า)
  • แปลงเป็นภาพขาวดำด้วยสูตร luma ITU-R 601: 0.299R + 0.587G + 0.114B หาร 255 · ภาพ 16 บิต หาร 65535 (ไม่ยืดคอนทราสต์รายภาพ เพื่อให้ผลคงที่)

2. ด่านกรองภาพ 3 ชั้น (ก่อนเข้าโมเดล)

  1. Modality gate (ชื่อไฟล์): ถ้าชื่อไฟล์มีคำ เช่น skin, face, selfie, fundus → บล็อก · ภาพสีมากกว่า 12% → ผ่านแต่มีคำเตือน
  2. Content gate (สถิติภาพ): คำนวณ 5–6 ค่าเพื่อจับภาพที่ “ไม่ใช่ OCTA ชัดๆ” เช่น
    • lag1 สหสัมพันธ์ของพิกเซลข้างเคียง < 0.25 → เป็น noise ไม่มีเส้นเลือดต่อกัน
    • detail (Laplacian) < 0.10 → ภาพเรียบ ไม่มีรายละเอียดเส้นเลือด
    • skew < 0.20 → ไม่ใช่เส้นเลือดสว่างบนพื้นมืด (ภาพกลับสี)
    • extremes > 0.60 → ดำ/ขาวล้วน (เป็นกราฟิก)
    • flat > 0.35 → มีพื้นที่เรียบมาก (รูปถ่าย, screenshot)
    ค่าเกณฑ์ตั้งจาก 39 ภาพ ROSE-O + ภาพที่ทำให้เบลอ/มืด/มี noise/บีบอัด JPEG/ย่อขนาด โดยเว้นระยะกว้าง
  3. Quality gate: คะแนน = 42 + contrast×0.52 + sharpness×0.22 − artifact×0.35 (0–99) · บล็อกถ้า < 45 หรือ contrast < 4 หรือพิกเซลมืดเกิน 92%

ถ้าโมเดลโหลดไม่ได้ ระบบตอบ analysis_status: unavailable และไม่แอบใช้วิธีสำรองแทน (no silent fallback) — เพื่อไม่ให้แพทย์เข้าใจผิดว่าเป็นผลจาก AI

3. U-Net แยกเส้นเลือด

  • U-Net = CNN รูปตัว U: ฝั่ง encoder ย่อภาพเพื่อจับ “ภาพรวม/บริบท” ฝั่ง decoder ขยายกลับเพื่อระบุ “ตำแหน่งละเอียด” มี skip connection ส่งรายละเอียดจาก encoder ข้ามไป decoder ทำให้เส้นเลือดเล็กๆ ไม่หาย เหมาะกับงานภาพการแพทย์ที่ข้อมูลน้อย
  • เทรนด้วย PyTorch แล้ว export เป็น ONNX (ไฟล์ ~7.4 MB) รันด้วย ONNX Runtime บน CPU — ไม่ต้องมี GPU ไม่ต้องติดตั้ง PyTorch บนเซิร์ฟเวอร์
  • Input: ภาพขาวดำ ย่อเป็น 256×256 (bilinear) หาร 255 → tensor [1,1,256,256] float32
  • Output: logits → sigmoid → ความน่าจะเป็นแต่ละพิกเซล → threshold 0.5 → mask → ขยายกลับขนาดเดิมด้วย nearest-neighbour
  • ตรวจ SHA-256 ของไฟล์โมเดลให้ตรงกับ model_card.json ก่อนใช้งาน ถ้าไม่ตรง → สถานะ corrupt (กันโมเดลถูกสลับ/เสีย)
  • Test Dice ใน model card = 0.708, split ตาม ROSE-O test ที่เผยแพร่ (9 ภาพ)

4. หา FAZ (ไม่ได้ใช้ AI — ใช้อัลกอริทึมภาพ)

  1. ย่อภาพเป็นกริด 304×304 (ภาพ 3×3 มม. → 1 พิกเซล = 3/304 มม.)
  2. Box blur 5×5 (ใช้ integral image / cumsum ให้เร็ว)
  3. พิกเซล “มืด” = ค่าน้อยกว่า 0.40 × median ของภาพ
  4. หาจุดที่มืดที่สุดในวงกลางรัศมี 15% ของภาพ เป็นจุดเริ่ม
  5. Flood fill (region growing) 4 ทิศ กระจายเฉพาะพิกเซลมืดที่ต่อกัน → ได้ FAZ mask
  6. พื้นที่ = จำนวนพิกเซล × (3/304)² mm² · ถ้าได้น้อยกว่า 0.02 หรือมากกว่า 1.5 mm² ถือว่าหาไม่เจอ ไม่รายงานดัชนี
  7. วาดเส้นขอบด้วย Moore-neighbour tracing เป็น SVG path ซ้อนบนภาพ

ค่าพารามิเตอร์ (0.40, blur 5×5) จูนจาก 30 ภาพเทรน แล้ววัดกับ 9 ภาพทดสอบ: Dice 0.87, คลาด 0.037 mm², r 0.92

5. ค่าอื่นที่รายงาน

  • Vessel density = พิกเซลเส้นเลือด ÷ พิกเซลทั้งหมด × 100
  • Perfusion density = % ของภาพที่สว่างกว่า “noise floor” ของ FAZ (ค่าเฉลี่ย FAZ + 3 SD) — เพราะ FAZ ไม่มีเลือดไหล ความสว่างในนั้นจึงเป็น noise ของเครื่อง · ครอบคลุม 94% ของเส้นเลือดที่ผู้เชี่ยวชาญวาด และติด FAZ ไม่ถึง 2%
  • ค่าเหล่านี้เทียบกับตัวเลขของเครื่อง OCTA โดยตรงไม่ได้ เพราะหน่วย/วิธีวัดต่างกัน

สูตรดัชนี Alzheimer และ % ความเสี่ยง (ต้องอธิบายได้)

ค่าอ้างอิงจากงานวิจัย: FAZ ชั้นผิว (superficial) ของคนปกติ = 0.275 ± 0.10 mm² (O'Bryhim et al., JAMA Ophthalmology 2018) · ผู้ป่วยอัลไซเมอร์มี FAZ ใหญ่กว่าเฉลี่ย 0.54 SD (SMD จาก meta-analysis, Frontiers in Aging Neuroscience 2022)

ขั้น 1  z  = (FAZ − 0.275) / 0.10          (จำกัดไว้ที่ −3 ถึง 3)
ขั้น 2  LR = exp(0.54·z − 0.54²/2)          = อัตราส่วนความน่าจะเป็น (likelihood ratio)
                                              ของกลุ่ม AD กับกลุ่มปกติ ที่ค่า z นี้
ขั้น 3  ดัชนี Alzheimer = LR / (1 + LR)       (prior 50/50 → 0.5 คือไม่บอกอะไร)
         Low < 0.35 ≤ Moderate < 0.65 ≤ High
ขั้น 4  % ความเสี่ยงตามอายุ (Bayes):
         odds_ก่อน = p_อายุ / (1 − p_อายุ)
         odds_หลัง = odds_ก่อน × LR
         risk     = odds_หลัง / (1 + odds_หลัง)

ทำไม LR เป็นสูตรนี้: สมมติ z ของคนปกติ ~ Normal(0,1) และของ AD ~ Normal(0.54,1) (SD เท่ากัน) อัตราส่วนความหนาแน่น = exp(0.54z − 0.54²/2)
